# Smart Hajj Assistance & Crowd Management System 

A smart system designed to enhance pilgrim safety and support crowd management during Hajj.

## Overview

The Smart Hajj Assistance & Crowd Management System was developed as an academic software engineering project.

The system focuses on helping pilgrims navigate crowded areas, receive important safety information, and access emergency support while providing tools for improved crowd monitoring and management.

## Key Features

- Real-time crowd tracking
- Smart navigation assistance
- Emergency alerts
- Multilingual support
- Pilgrim safety assistance
- Medical wearable integration
- Crowd management support
